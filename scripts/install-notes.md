# Install notes

## Wazuh server (Ubuntu Server 20.04, ARM64, UTM)
```bash
# 1. Extend the LVM root volume (installer only allocated 30 of 60 GB)
sudo vgs                                   # check VFree
sudo lvextend -l +100%FREE -r /dev/ubuntu-vg/ubuntu-lv
df -h /

# 2. All-in-one install (manager + indexer + dashboard)
sudo apt update && sudo apt upgrade -y
curl -sO https://packages.wazuh.com/4.14/wazuh-install.sh
sudo bash ./wazuh-install.sh -a -o

# 3. Retrieve the admin password (never commit it)
sudo tar -O -xvf wazuh-install-files.tar wazuh-install-files/wazuh-passwords.txt
```

## Kali agent
```bash
# Ensure /var/log/auth.log exists so SSH events are collected
sudo apt install -y rsyslog && sudo systemctl enable --now rsyslog

# Agent install command generated by: Dashboard -> Deploy new agent (DEB aarch64)
sudo systemctl daemon-reload
sudo systemctl enable --now wazuh-agent
sudo systemctl start ssh
```

## Custom rule
```bash
sudo nano /var/ossec/etc/rules/local_rules.xml   # add configs/local_rules.xml
sudo systemctl restart wazuh-manager
sudo /var/ossec/bin/wazuh-logtest                 # optional: test rules offline
```
